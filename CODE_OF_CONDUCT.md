# Code of conduct

This project is about code. Keep issues, pull requests and comments about the work. Anything else is not tolerated.

## Expected

- Be respectful and assume good faith.
- Criticize code and ideas, not people.
- Stay on topic.

## Not accepted

- Insults, personal attacks and harassment.
- Threats.
- Spam.
- Publishing someone's private information without their permission.

## Enforcement

Report a problem to caio.dscamara@gmail.com. Reports stay private. The maintainer reviews each one and may edit or delete content, or block someone from the project.
